# Verified live mug profile

This compact profile enables the existing dinner suite with stereo visual correction during late mug placement. It binds the exact passing physical protocol, development/final reports, unchanged observer/motor models and evaluated controller dependencies. No original model is replaced. Missing or modified dependencies are refused.

Choose **Learned dinner · live mug vision** and say/type **Set the table**. Standard and farther-left starting presets are supported. Individual mug commands use the original dinner mode because this correction was evaluated in complete workflows.

The separately frozen final comparison passes 20/20 full workflows with live images, 20/20 with the original baseline, and 0/20 with frozen images. Thus it establishes bounded live-feedback benefit against the frozen control, without an improvement in success over the original baseline on these scenes. The [physical evidence](../../docs/robotics/evidence/mug-visual-correction-v2/README.md) retains every attempted case. The [entry-point regressions](../../docs/robotics/evidence/visual-mug-deployment-v1/README.md) retain both preview attempts and verify identical recorded physics after the display-only repair.

Only late mug placement uses current stereo images; other skills retain initial RGB conditioning and motor-feedback progress guards. Arbitrary reachable positions/destinations, pouring and airborne handoffs remain unfinished. OpenVINO CPU is the supported runtime for this option. Intel execution of the preceding six-skill baseline does not automatically verify this newer observer/motor integration.
