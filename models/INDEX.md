# Model guide

The demonstrated profile is **`dinner_visual_mug_v1/profile.json`**. It combines `dinner_suite` (six skills and the four relay legs), `bottle_visual`, `bottle_relays`, `mug_keypoint_observer_v1` and `mug_correction_motor_v2`.

The remaining model directories preserve published optional modes or stopped research: `bottle_primitive` is the older bottle practice model; `bottle_wide_v1`, `bottle_servo_v1` and `bottle_refinement_v1` support separate wider-bottle work; `mug_visual_observer_v1`, `mug_release_v1` and `spoon_release_v1` are unpromoted candidates. Their presence does not imply that the selected demo uses them or that their experiments passed.

Model version suffixes and filenames are immutable provenance, not presentation drafts. All previously published model bytes are retained. Each directory contains its original description, exports and metrics. Historical relative references and complete reproduction manifests resolve in the [development snapshot](../docs/ARCHIVE.md).
